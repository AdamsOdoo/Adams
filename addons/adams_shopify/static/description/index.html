Why Choose Adams Shopify Connector?

This is not another thin wrapper around the Shopify REST API. Adams Shopify Connector is an enterprise-grade integration built for real-world e-commerce operations at scale.

Built-In Promoter System

Most Shopify connectors stop at syncing orders and products. Adams includes a full promoter and coupon management system -- create promoters, generate discount codes, track usage per order, and calculate commissions. No extra module required.

Circuit Breaker Resilience

Network failures and API outages happen. The built-in circuit breaker pattern automatically detects failures, stops sending requests to a failing endpoint, and recovers gracefully -- preventing cascading errors across your sync jobs.

Reconciliation and Drift Detection

Data drifts silently over time. Adams periodically compares Odoo and Shopify records, flags discrepancies, and lets you resolve them before they affect your operations. No more discovering stock mismatches weeks later.

Modern GraphQL API

Uses Shopify's modern GraphQL Admin API (version 2026-01) for optimal performance. Fetch exactly the data you need in a single request instead of paginating through REST endpoints. Faster syncs, lower API cost.

Checksum-Based Efficiency

Every synced record carries a checksum. On each sync cycle, only records with actual changes are processed. For a catalog of 10,000 products where 50 changed, only 50 API calls are made -- not 10,000.

Complete Feature Coverage

Products, orders, customers, inventory, fulfillments, collections, refunds, gift cards, metafields, tax mapping, payment gateways, locations, and webhooks. One module covers the entire Shopify integration surface.

Architecture Highlights

  • GraphQL Admin API -- Shopify API version 2026-01 for maximum efficiency
  • Adaptive Rate Limiting -- Reads throttle cost from every GraphQL response and adjusts request pacing automatically
  • Binding Pattern -- Clean separation between Odoo records and Shopify mappings via dedicated binding models
  • Idempotent Operations -- Safe to retry any operation; duplicate protection enforced at the database level
  • Async Webhook Processing -- Webhooks are received instantly and processed asynchronously to avoid blocking Shopify
  • Comprehensive Logging -- Detailed sync logs, webhook logs, and error logs with full traceability
  • No External Dependencies -- Uses only the Python requests library included in standard Odoo deployments

Setup in 5 Minutes

  1. Install the module
  2. Go to Shopify > Configuration > Shopify Stores
  3. Enter your shop URL and access token
  4. Click Test Connection to verify API access
  5. Follow the Onboarding Wizard to configure sync settings, register webhooks, and run your initial import
  6. Scheduled sync takes over automatically -- you are done

Requirements

  • Odoo 19.0 (Community or Enterprise)
  • Shopify store with a Custom App access token
  • Required Shopify API scopes: read/write products, customers, orders, inventory, fulfillments, locations, gift cards
  • Python requests library (included in standard Odoo deployments)
