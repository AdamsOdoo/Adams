Adams Shopify Connector

Sync products, orders, customers and inventory with Shopify

A production-grade, bidirectional integration between Odoo and Shopify. Built for reliability, performance, and ease of use.

Key Features

Product Sync

  • Bidirectional product synchronization
  • Variant mapping with SKU matching
  • Automatic change detection via checksums
  • Bulk import for initial setup

Order Import

  • Automatic order import from Shopify
  • Customer resolution with email deduplication
  • Line items, discounts, shipping, and taxes
  • Auto-confirm orders based on payment status

Customer Sync

  • Import customers with address handling
  • Intelligent deduplication by email
  • Multiple address support
  • GDPR-compliant data handling

Inventory Push

  • Push stock levels from Odoo to Shopify
  • Support for free quantity or on-hand quantity
  • Warehouse-specific inventory
  • Batch updates for performance

Real-time Webhooks

  • HMAC-verified webhook processing
  • Automatic deduplication
  • Async processing via cron
  • Full audit trail of webhook events

Dashboard & Monitoring

  • At-a-glance sync health per store
  • Detailed sync and webhook logs
  • Error visibility with one-click retry
  • Automated reconciliation checks

Architecture Highlights

  • GraphQL API — Uses Shopify's modern GraphQL Admin API (2026-01) for optimal performance
  • Rate Limiting — Adaptive rate limiter that reads Shopify's throttle status from every response
  • Multi-Company — Full multi-company support with company-scoped backends and record rules
  • Multi-Store — Connect and manage multiple Shopify stores from a single Odoo instance
  • Binding Pattern — Clean separation between Odoo records and Shopify mappings
  • Checksum-based Change Detection — Only syncs records that have actually changed
  • Idempotent Operations — Safe to retry; duplicate protection via database constraints
  • GDPR Compliance — Handles mandatory Shopify privacy webhooks (data_request, customer/shop redact)

Setup in 5 Minutes

  1. Install the module
  2. Go to Shopify > Configuration > Shopify Stores
  3. Enter your shop URL and access token
  4. Click Test Connection
  5. Click Register Webhooks
  6. Go to Shopify > Operations > Import Data for initial import
  7. Scheduled sync takes over automatically

Requirements

  • Odoo 19.0 (Community or Enterprise)
  • Shopify store with a Custom App access token
  • Required Shopify scopes: read/write products, customers, orders, inventory, fulfillments
  • Python requests library (included in standard Odoo deployments)
