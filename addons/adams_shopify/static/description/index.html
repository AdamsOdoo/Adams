Adams Shopify Connector

The Most Complete Shopify Integration for Odoo 19

Synchronize products, orders, customers, inventory, fulfillments, refunds, payouts, collections, gift cards, metafields, and more between Odoo and Shopify. Built on Shopify's latest GraphQL Admin API (2026-01) for maximum performance and future-proofing. Connect multiple Shopify stores to a single Odoo instance with full multi-company and B2B isolation support.

Why Adams Shopify Connector?

GraphQL-Native

Built entirely on Shopify's modern GraphQL API — not the deprecated REST API. Faster, more efficient, and future-proof.

B2B + DTC Coexistence

Sell wholesale through Odoo and direct-to-consumer through Shopify from the same system. Sales channel isolation keeps them separate.

Self-Healing Sync

Automated reconciliation, drift detection, dead-letter queues, and smart retry logic. Recovers from problems on its own.

B2B and Wholesale Isolation

Sell B2B through Odoo and direct-to-consumer through Shopify — from the same system, without interference. No other Shopify connector offers this.

  • Sales channel separation: Every order is tagged as "direct" (B2B) or "shopify" (DTC)
  • Automatic gating: Only Shopify orders trigger sync actions
  • B2B privacy: Wholesale orders, custom pricing, and direct sales are never sent to Shopify
  • Shared catalog: Same products, different pricing via Odoo pricelists

Get Started in 5 Minutes

  1. Install the module from the Odoo Apps Store
  2. Go to Shopify > Configuration > Shopify Stores
  3. Enter your shop URL and Shopify Admin API access token
  4. Click Test Connection to verify
  5. Follow the Onboarding Wizard to configure and run your initial import
  6. Automated sync takes over — you're done!

Requirements

  • Odoo 19.0 (Community or Enterprise)
  • Shopify store (Basic plan or above) with a Custom App access token
  • API scopes: read/write products, customers, orders, inventory, fulfillments, locations, gift cards, discounts
  • Dependencies: adams_base, sale_management, stock, account, mail (all standard Odoo modules)
  • No external Python packages required beyond standard Odoo
