Frequently Asked Questions

Quick answers to the questions we hear most from Odoo Customers.

Does this application compatible with both Odoo Enterprise and Community editions?

Yes. Fully compatible with Odoo Enterprise (On-premise and Odoo.SH) and Odoo Community. Not compatible with Odoo Online (SaaS) as it does not support third-party apps.

Which Shopify plan is required to use this connector?

A Shopify Grow plan or higher is required. Shopify classifies customer information such as name, email, phone number, and address as Level 2 Personally Identifiable Information (PII). Since the connector accesses this information through a Shopify custom app/API, Shopify requires the store to be on the Grow plan or higher. The Basic plan does not provide access to Custom Level 2 PII apps.

How is this different from other connectors?

Built on Shopify’s GraphQL API from v1. Payout imports and Enterprise auto-reconcile where applicable. Fraud analysis per order. Managed queue with error isolation.

What happens if a sync fails?

One bad record never blocks the queue. Each failure is logged with Shopify record ID, error message, and a direct link to fix it.

Can I connect multiple Shopify stores?

Unlimited stores. Each gets its own credentials, product matching, payment mappings, warehouse, pricelist, and webhooks.

How do partial refunds work?

Sales order → Register Payment → check “Refund in Shopify” → confirm. Credit note created automatically.

Does it sync products by SKU only?

Three modes: SKU, Barcode, or Both. “Both” checks SKU first, falls back to barcode. Configure per instance.

Is SSL (HTTPS) required for Webhooks?

Yes. Shopify requires a secure endpoint. HTTPS and database filter must be enabled. On Odoo.sh this is automatic.

Can I migrate from another connector?

Yes. Products matched via SKU/Barcode: no duplicates. Set the import date to your switch date.

What is the Base Marketplace dependency?

Qamah Solutions’ shared infrastructure: listing management, queue jobs, instance management, analytics. Installs automatically. No extra purchase.

How can I handle product pricing using the integration?

The integration enables you to synchronize prices from Odoo to Shopify using a pricelist. You can set up a pricelist for each Shopify instance in Odoo and then update the prices to Shopify through the designated pricelist. Importing prices from Shopify to Odoo is also possible, but it's important to note that these prices will be imported into the pricelist and not directly to the product.
