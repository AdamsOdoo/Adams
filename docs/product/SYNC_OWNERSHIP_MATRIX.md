# Sync Ownership Matrix

## Purpose

Define which system owns each entity after setup and how changes flow between Odoo and Shopify. Goal 0 creates the schema only; Goal 1+ must populate rows from verified behavior and confirmed decisions.

## Matrix Schema

| Entity | Master system | Direction | Trigger mode | Manual/scheduled/webhook/Odoo event/reconciliation | Conflict behavior | Notes | Status |
|---|---|---|---|---|---|---|---|

No rows are populated in Goal 0.
