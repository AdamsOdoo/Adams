# 02 — Product

**Purpose:** product definition derived from research — vision, personas, user
stories, scope, feature taxonomy, and MVP scope for the Odoo 19 Shopify
Connector.

**What belongs here:** `product-vision.md`, `feature-taxonomy.md`,
`mvp-scope.md`, personas/user stories — all evidence-grounded and traceable to
research.

**What does not belong here yet:** a *finalized/locked* MVP scope. During the
research phase these are **implications and candidates** (recommendations), not
decisions. Architecture and code do not belong here.
