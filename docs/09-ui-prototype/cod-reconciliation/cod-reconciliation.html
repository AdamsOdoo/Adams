COD reconciliation workspace

The cash-on-delivery control surface. Every COD order is described by three independent dimensions — commercial, fulfillment, collection — never one merged status; every order carries the five-value ledger (original / fulfilled / collected / outstanding / cancelled). The Connector User records collections; only the Connector Administrator resolves discrepancies. States: loaded (with ledger card, partial-collection drawer, and discrepancy card), empty (education), loading, discrepancy-heavy.

No COD orders
Cash-on-Delivery tracking starts when a Connector Administrator adds a manual payment gateway (like “Cash on Delivery”) to this store’s approved list in Configuration. A manual gateway that is not on the list is treated like any ordinary pending payment — nothing appears here. Orders are recognized as COD by their payment-transaction evidence, never by a pending status alone.
