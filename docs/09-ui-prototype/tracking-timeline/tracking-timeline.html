Where a parcel physically is — carrier milestones for one fulfillment, shown as a vertical timeline with the raw Shopify value preserved behind every label. A milestone is display only: it never validates Odoo stock and never changes the connector’s reconciliation state. The state-taxonomy strip above the timeline keeps every state dimension a separate, labeled badge (the four-layer status taxonomy — Shopify Layer-A families, connector-derived states, and the Odoo delivery state).
