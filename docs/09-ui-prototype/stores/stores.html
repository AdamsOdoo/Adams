Stores — list & detail

Per-store lifecycle surface. The list shows every store as a premium card with its lifecycle badge (the five shipped states: setup incomplete, connected, reconnect needed, disconnecting, disconnected), a health strip, the connection generation, enabled capabilities, and quick stats. The detail view carries the lifecycle actions — reconnect and disconnect are Connector-Administrator only; a Connector User sees the same data read-only. Disconnect explains quiescence honestly (open in-flight work is allowed to finish, bounded by a 15-minute timeout). Copy is illustrative (MBQ-22); no backend method or field is asserted.

Disconnect Adams Home?

Disconnecting stops all synchronization for this store. Here is exactly what happens:

  1. No new work is admitted — from the moment you confirm, no new sync job can start for this store.
  2. In-flight work finishes safely — 2 jobs are currently running. The store shows Disconnecting while they complete (quiescence), bounded by a 15-minute timeout.
  3. Everything is preserved — settings, mappings, bindings, history and logs are kept. Nothing is deleted. You can reconnect at any time.
External changes made in Shopify while disconnected are caught up on reconnect as normal updates or review cases — never replayed blindly.
