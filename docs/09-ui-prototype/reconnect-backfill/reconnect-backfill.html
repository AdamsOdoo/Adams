Reconnect, catch-up & backfill

Controlled re-entry after a disconnection: the eight-step reconnect sequence (verify → new connection generation → historic jobs preserved, never executed → fresh domain scans), per-domain catch-up driven by timestamp watermarks with an overlap window, and the Administrator-only historic order backfill with a mandatory read-only preview and honest 60-day / read_all_orders messaging. Nothing from before the disconnect is ever replayed blind. Visual prototype only — copy illustrative; no RPC or model invented.
