Inventory workspace

The inventory sync surface for the Odoo→Shopify quantity export: per-mapped-location free_qty is the exported figure, every push is a read→compare→set (compareQuantity CAS) cycle, pending pushes coalesce last-value-wins, the Shopify→Odoo direction is read/verify only (divergences become review cases), and the first push per mapped pair is guarded by a baseline preview an Administrator confirms. Visual prototype only — copy is illustrative; no RPC, model, or field contract is invented.
