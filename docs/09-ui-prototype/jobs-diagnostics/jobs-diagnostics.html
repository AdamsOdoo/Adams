Resolve manual review — drawer · the six sub-reasons (words + internal token in specs only) · 1366px

Waiting on a decision — Customer import · j.okafor@example.com

This job stopped because it needs a person to decide. It is one of six decision types the connector can raise:

Decision typeWhat it means
Ambiguous match this caseTwo or more existing records share the same identity evidence — pick the right one.
Binding conflictThe record is already linked to a different counterpart — untangle before syncing.
Duplicate riskContinuing might create a duplicate — confirm it is safe first.
Destructive write blockedThe change would overwrite or remove data — the guard stopped it for confirmation.
Inventory location missingA Shopify location has no mapped Odoo location — map it, then re-run.
Notification confirmation missingA fulfillment would notify the customer — an explicit confirmation is required.
Resolving opens the matching screen with both candidates. Your decision is recorded — who, when, what — and the job then finishes on its own.

Global state gallery · the 11 canonical UI states — compact reference cards used across every connector surface · 1366px
Canonical UI statesReference — every surface expresses these consistently; state word always visible, color reinforces
1 · Empty
Nothing here yet
Guided: say why it’s empty and name the one next action. Illustration allowed here only.
2 · Loading
Skeleton + honest line. Never blank, never fake-instant.
3 · Warning
Needs attention
Degraded but operating; cause + one action.
4 · Success
All clear
Affirmative, quiet. Resolved incidents labelled “resolved”, never counted as active.
5 · Failure
Failed
Technical error: reason, fix, owner, retry path. Never a raw stack trace as the primary message.
6 · Offline
Unreachable
Counterpart down. Jobs hold with backoff; data labelled last-known.
7 · Reconnecting
Reconnecting…
Recovery in progress: verify → readiness → fresh catch-up scans, with per-domain progress.
8 · Stale
As of 09:52
Data older than its cadence promises — always timestamped, never silently presented as fresh.
9 · Delayed
Running late
Work queued longer than expected (backlog/throttle). Cause + pace shown; nothing lost.
10 · Partial
7 of 9 done
Some items succeeded, some didn’t. Exact split + a path to the remainder; never rounded up to success.
11 · Unknown schema
Unverified shape
The counterpart answered with something we haven’t verified (e.g. version fell forward). Fail closed: hold for review, never guess.
