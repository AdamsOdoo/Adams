# Error Log

## Format
Each error entry tracks: discovery, root cause, fix, regression test, and prevention.

| Bug ID | Date | Description | Root Cause | Fix | Regression Test | Status |
|--------|------|-------------|-----------|-----|----------------|--------|
| - | - | No errors logged yet | - | - | - | - |

## Error Categories
- RACE_CONDITION: Concurrent operations causing duplicates or conflicts
- API_ERROR: Shopify API returning unexpected responses
- DATA_ERROR: Invalid or missing data in sync payloads
- TRANSACTION: Odoo transaction/savepoint issues
- PERFORMANCE: Timeout, memory, or slow query issues
- SECURITY: Authentication, authorization, or injection vulnerabilities
