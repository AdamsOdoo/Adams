Consequence: every Odoo cursor (cron drain, RPC request) runs at PostgreSQL
REPEATABLE READ (snapshot isolation). A single run_drain transaction takes ONE
snapshot at its first read (the claim). invalidate_recordset() clears the ORM cache
but a re-SELECT still returns snapshot data, so checkpoint-3 cannot observe a
disconnect committed by another transaction AFTER the drain's snapshot.
