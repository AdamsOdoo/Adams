## Findings addressed

- Saved Sales selections were missing from browser preferences and report return.
  Prior qualified continuation adds selection-only persistence and stale-response
  suppression; no business rows or values enter saved preferences.
- Unified record search was absent. Added an allowlisted ORM document search and
  separately reauthorized native form action. Both validate dashboard membership,
  active company, date scope, query length and record identity. Native model/field
  access and record rules apply without sudo. Hidden results never become counts.
- Summary export/print was absent. Added server-side native report reevaluation,
  export-group checks and scope/provenance. Client values are never accepted as
  accounting data. Unavailable results stay blank with their status. Text cells
  neutralize spreadsheet formulas while numeric negative values remain numeric.
- Company changes could allow a pending new export/search/print result to appear.
  Added generation/identity guards and immediate cleanup, with focused regressions.
- Management attention incorrectly described restricted finance as unconfigured.
  It now derives the missing-window status from the native payable metric.
- Mobile workspace links did not close the rail. Links now close it and reveal the
  destination. Sales initial auto-load respects a user selection already made.
