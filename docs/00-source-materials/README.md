# 00 — Source Materials

Raw captured source material so research survives link rot: saved excerpts,
quotes, and screenshot references — **always with a citation** (vendor/product +
URL + access status + date).

## What belongs here

- Per-source subfolders, e.g. `webkul/`, `teqstars/`, `emipro/`,
  `ventortech/`, `odoo-apps/`, `shopify-api/`, `odoo-docs/`.
- Short excerpts/quotes and notes about where each screenshot appears.
- A citation header on every captured file (source URL, access status, date).

## What does NOT belong here

- Conclusions, feature matrices, or competitor profiles → those go in
  `/docs/01-research`.
- Content obtained by **bypassing** an authentication wall — never capture
  gated content that requires defeating access controls. Record such sources as
  **Blocked** in the resource inventory instead.
- Large binary dumps; capture only what is needed for evidence.
