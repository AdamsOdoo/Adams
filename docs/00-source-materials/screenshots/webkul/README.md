# Webkul (R1) — screenshots

> Visual evidence for **Webkul — Odoo Multichannel Shopify Connector** (R1).
> Source: https://webkul.com/blog/odoo-multichannel-shopify-connector/
> (+ store page). Accessed 2026-06-30.

- **Binary files saved here:** none. Pages were read via the proxy fetcher
  (markdown/alt-text), so captions and field labels are reliable but pixels were
  not inspected; saving binaries was judged impractical for the analytic gain
  (sprint rule allows the markdown-inventory fallback).
- **Analysed inventory:** see the `Webkul (R1)` section of
  [`../../competitor-screenshot-inventory.md`](../../competitor-screenshot-inventory.md)
  — groups **WK-SETUP (S1–S7)**, **WK-CONFIG (S8–S10)**, **WK-CRON (S11–S13)**,
  **WK-FEEDS (S14)**, **WK-OPS (S15–S21)**.
- **Key UX takeaways:** explicit **Test Connection** validation step; tab-segmented
  config (Basic/Sales/Product); a **Feeds** staging area with an error-feed
  recovery queue; raw cron internals exposed to users (a thing to avoid).
- Allowed extensions if files are later added: `.png .jpg .jpeg .webp`.
