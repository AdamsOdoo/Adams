## Capture policy (per `CLAUDE.md` §7 and `research-methodology.md` §5)

- **Analysis over existence.** Each visual is analysed for what it shows about
  configuration, workflow, layout, labels, status indicators, logs, buttons, and
  errors — not merely listed. The analysis lives in the inventory file.
- **Evidence, not decoration.** Every visual entry cites its **source URL** and
  the **date accessed** (2026-06-30), and is **claim-classified** (a screenshot
  that demonstrates a flow is a *visible demonstrated workflow*; a marketing
  graphic is a *competitor claim*).
- **No auth bypass.** Visuals behind sign-in walls (e.g. gated Confluence
  children, the Google Doc) are **recorded as blocked, never captured**.
- **Binary image files are optional.** Where saving an image is impractical
  (JS-rendered, heavy, or auth-gated) the inventory records the visual in
  markdown with "Actual file saved: no" and the reason. Allowed image
  extensions if saved: `.png`, `.jpg`, `.jpeg`, `.webp`.
