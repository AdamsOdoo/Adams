**Purpose:** project-scoped Claude Code **skills** — small, reusable routines
that save repeated prompt overhead (e.g. researching a source, running a
session handoff) while enforcing the project's rules.

**What belongs here (later):** narrow, **docs-only** skills with citation,
claim-classification, and handoff requirements baked in.

**What does not belong here yet:** active skills.

## Recommendation: defer

> **Skills and agents should be created later, after the research workflow
> stabilizes. Do not create active skills or agents now, because premature
> automation may encode weak assumptions** into the workflow before the
> methodology, feature taxonomy, and review gates are settled.

A skill should be added only once (a) the routine it encodes has been performed
manually enough times to be well understood, and (b) ChatGPT approves its scope.
